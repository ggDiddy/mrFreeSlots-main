## 🚨 COMMON PITFALLS TO AVOID

### SEO Mistakes
❌ **Keyword Stuffing** — don't force keywords unnaturally (already optimized perfectly)  
❌ **Duplicate Content** — every page must be unique  
❌ **Over-Optimized Anchors** — never exceed 10% exact match in backlinks  
❌ **Ignoring Mobile** — 70% of iGaming traffic is mobile  
❌ **Slow Page Speed** — every second delays = 7% conversion drop  

### Link Building Mistakes
❌ **Buying Fiverr Links** — 99% are spam, will hurt rankings  
❌ **PBN Networks** — Google detects and penalizes  
❌ **100+ Links in 1 Month** — unnatural velocity, red flag  
❌ **Ignoring Anchor Text Ratio** — track in spreadsheet monthly  

### Compliance Mistakes
❌ **No 18+ Warning** — required in all markets  
❌ **No T&Cs on Bonuses** — can get affiliate account terminated  
❌ **No Responsible Gambling Info** — Google penalizes YMYL sites without this  
❌ **Misleading Bonus Claims** — "FREE!" without mentioning wagering = ASA violation (UK)

### If You Need Help

3. **Link Building:** Follow `BACKLINK-STRATEGY.md` step by step
4. **Design Tweaks:** All colors are CSS variables in `:root` — easy to customize

### Customization Guide
**To change colors:**
Edit `css/style-premium.css`, lines 15-30 (`:root` variables):
```css
:root {
  --accent-gold: #F5A623;  /* Change to your brand color */
  --primary-bg: #0D0D1A;   /* Change background */
}
```

**To add new casino:**
Copy existing `.casino-card` block in `index-premium.html` and update:
- Casino logo image
- Casino name
- Bonus amount
- Features list
- CTA link

**To change fonts:**
Replace Google Fonts link in `<head>`:
```html
<link href="https://fonts.googleapis.com/css2?family=YourFont:wght@400;700&display=swap" rel="stylesheet">
```
Then update `font-family` in CSS.
